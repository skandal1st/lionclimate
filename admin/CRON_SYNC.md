# Синхронизация цен с поставщиками (раз в сутки)

Скрипт `sync-prices.php` обходит все товары, у которых указана **ссылка на страницу поставщика**, загружает страницу и обновляет цену в каталоге, если на сайте поставщика она изменилась.

## Настройка cron на сервере

### Вариант 1: вызов по HTTP (рекомендуется)

На сервере откройте crontab:

```bash
crontab -e
```

Добавьте строку (запуск каждый день в 03:00):

```
0 3 * * * curl -s "https://lionclimate.ru/admin/sync-prices.php?key=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ"
```

**Секретный ключ** задаётся в `admin/config.php` — константа `CRON_SECRET_KEY`. По умолчанию там значение вида `lion_sync_xxxx`. Для безопасности замените на свой случайный ключ (например сгенерируйте: `echo -n "mysecret" | md5sum`) и подставьте в URL.

Пример с вашим ключом:

```
0 3 * * * curl -s "https://lionclimate.ru/admin/sync-prices.php?key=lion_sync_5d41402abc4b2a76b9719d911017c592"
```

### Вариант 2: вызов PHP из консоли

Если предпочитаете не открывать URL из крона:

```bash
0 3 * * * cd /var/www/lionclimate.ru && php admin/sync-prices.php
```

В этом случае ключ в URL не нужен (скрипт определяет запуск из CLI).

## Проверка

- Вручную по HTTP: откройте в браузере  
  `https://lionclimate.ru/admin/sync-prices.php?key=ВАШ_КЛЮЧ`  
  Должен вернуться JSON с полями `updated`, `errors`, `log`.

- Из консоли:  
  `cd /var/www/lionclimate.ru && php admin/sync-prices.php`

## Важно

- Синхронизация затрагивает только товары, у которых в карточке заполнена **«Ссылка на страницу поставщика»** (при импорте по ссылке она подставляется автоматически).
- Поддерживается поставщик **proclimate5.ru**. При изменении вёрстки их сайта парсер может потребовать правок в `admin/supplier-parser.php`.
