# Настройка Telegram интеграции

Для работы форм обратной связи необходимо настроить Telegram бота.

## Шаги настройки:

### 1. Создание Telegram бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и создайте бота
4. После создания бота вы получите **токен** (пример: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Получение Chat ID

Есть несколько способов получить ваш Chat ID:

#### Способ 1: Через бота @userinfobot
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Бот автоматически отправит ваш Chat ID

#### Способ 2: Через бота @getidsbot
1. Откройте [@getidsbot](https://t.me/getidsbot)
2. Отправьте любое сообщение
3. Бот покажет ваш Chat ID

#### Способ 3: Через API
1. Отправьте любое сообщение вашему боту
2. Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. Найдите `"chat":{"id":` в ответе - это ваш Chat ID

### 3. Настройка в send-telegram.php (рекомендуется)

Откройте файл `send-telegram.php` и найдите строки:

```php
$TELEGRAM_BOT_TOKEN = 'YOUR_BOT_TOKEN';
$TELEGRAM_CHAT_IDS = [
    'YOUR_CHAT_ID_1', // Менеджер
    'YOUR_CHAT_ID_2'  // Руководитель
];
```

Замените:
- `YOUR_BOT_TOKEN` на токен вашего бота
- `YOUR_CHAT_ID_1` на Chat ID менеджера
- `YOUR_CHAT_ID_2` на Chat ID руководителя

Пример:
```php
$TELEGRAM_BOT_TOKEN = '123456789:ABCdefGHIjklMNOpqrsTUVwxyz';
$TELEGRAM_CHAT_IDS = [
    '123456789',  // Менеджер
    '987654321'   // Руководитель
];
```

**Примечание:** Можно указать любое количество получателей, просто добавьте новые Chat ID в массив `$TELEGRAM_CHAT_IDS`.
