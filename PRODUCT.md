# Lion Climate — PRODUCT

**Что это.** Компания по продаже, установке и обслуживанию кондиционеров (сплит-систем) в Москве и Московской области. Розница и опт.

**Кому.** Владельцы квартир, домов и офисов в Москве/МО, которым нужен подбор, монтаж «под ключ» и сервис; а также оптовые покупатели.

**Что важно донести (Persuade).**
- Продажа + профессиональный монтаж + обслуживание — берут проект целиком.
- Гарантия на монтажные работы — 1,5 года.
- 7 лет на рынке; рейтинг 5.0 на Авито (20 отзывов).
- Бренды: Daikin, Hitachi, Samsung, MDV и др.
- Аккуратность (чистка после монтажа), быстрый выезд, без выходных.

**Действие.** Оставить заявку / узнать цену / позвонить (+7 968 823 45 73, lklimate@mail.ru).

**Фактические данные — не выдумывать:** цены, конкретные ТТХ моделей, число отзывов/рейтинг, гарантийные сроки, телефон/почта. Реальные фотографии есть только для раздела «Галерея работ».

**Технически.** Публичный сайт — React + Vite (`frontend/`), общий стиль в корневых `styles.css` / `catalog.css` / `product-card.css`. Каталог/товары приходят из API (`server/`). Метрика Яндекс. Деплой собирает `frontend` → `dist`. Корневые `index.html`/`catalog.html`/`product.html` — легаси-прототипы, не деплоятся.
